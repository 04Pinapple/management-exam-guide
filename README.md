# management-exam-guide

把 47 张管理学试题照片，整理成一份中英双语、按章节归纳的复习提纲。

Turning 47 photos of management exam questions into a bilingual, chapter-organized review guide.

---

## 背景 | Why

复习时手上只有一堆试题照片：有重复拍摄的、有拍歪的、有被手指挡住的，还有几张模糊到只能看清大意。逐张翻着复习效率很低，而且同一个概念在不同题里用了不同说法。

> All I had before the exam was a folder of 47 phone photos — duplicated shots, tilted pages, a finger over the corner, a few too blurry to read precisely.

所以做了一件事：把照片里的题按章节归类，抽出考点术语，统一中英表达，做成一份能检索、能批注的 Markdown 提纲。

## 产出 | What's inside

- 覆盖第 1-4、6-8 章（照片中没有第 5 章的题）
- 每个知识点给**中文定义 + 英文对照 + 记忆提示**，对比类概念用表格
- 文末三块：**易混概念速查**、**简答题作答框架**、**考前复习建议**

## 做法 | How

1. **先归类再总结**：按题面判断属于哪一章，避免模型把「效率 / 效果」这类相近概念混在一段里
2. **术语统一**：同一个概念固定一个中文译法和一个英文对应词，方便考前快速回查
3. **去重**：重复拍摄的题只保留信息最完整的那张
4. **人工校对**：照片上的手写勾选不作为标准答案，只当作「这题被重点标记过」的线索

## 局限 | Limitations

- 照片存在模糊和遮挡，个别题面只能识别大意
- 第 5 章没有对应照片，未收录
- 这是一份**考点与概念的整理**，不是官方答案，不保证答题完整度
